# RegexSolver Python API Client

> [!WARNING]
> **Retired.** The hosted RegexSolver API this client calls was shut down in
> November 2026, so the client no longer works. This repository is archived
> and the package on PyPI gets no further releases.

## What to use instead

RegexSolver lives on as an open-source Rust library:
[regexsolver](https://github.com/RegexSolver/regexsolver)
([crates.io](https://crates.io/crates/regexsolver),
[documentation](https://docs.rs/regexsolver)). It offers the operations this
client exposed (intersection, union, difference, complement, equivalence,
subset, cardinality, length, string generation and more), runs locally, and
needs no API token.

To try an operation without installing anything, use the demo on
[regexsolver.com](https://regexsolver.com): it runs the library in your
browser.
